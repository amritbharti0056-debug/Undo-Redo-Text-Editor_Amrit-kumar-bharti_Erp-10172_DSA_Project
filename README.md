Undo-Redo Text Editor

Project Description

The Undo-Redo Text Editor is a Java-based application that allows users to write and edit text. It uses Stack and Linked List data structures to perform undo and redo operations.

Features

- Insert text
- Undo operation
- Redo operation 
- View document
- Save text into a file
- Load previously saved text

Data Structures Used

- Stack – For Undo and Redo operations.
- Linked List – For storing document lines.

Technologies Used

- Programming Language: Java
- IDE: VS Code
- Concepts: Data Structures and Algorithms

How to Run

1. Install Java JDK.

2. Download or clone this repository.

3. Open the project folder in VS Code.

4. Compile the Java file:
   
   "javac UndoRedoEditor.java"

5. Run the program:
   
   "java UndoRedoEditor"
